# Tailwind CSS Practice Projects

A collection of React + Tailwind CSS practice projects completed.

## Live Link: https://tailwindmini.netlify.app/ 



## 🚀 Projects

### 1. Netflix-Inspired Navbar

A responsive streaming-platform style navbar built with React and Tailwind CSS.

**Concepts Practiced**
- Flexbox
- Spacing
- Alignment
- Responsive breakpoints
- Hover states
- Sticky navbar
- Typography
- Colors

---

### 2. YouTube Sidebar

A YouTube-inspired responsive sidebar with navigation items and a main content area.

**Concepts Practiced**
- Flexbox
- Sidebar layout
- `flex-1`
- Grid
- Responsive design
- Spacing
- Hover effects
- Shadows
- Rounded corners

### 3. LinkedIn Profile Card

A professional profile card inspired by social networking profile layouts.

**Concepts Practiced**
- Card design
- Profile image

- Statistics layout

- Hover effects
- Image handling
- `object-cover`

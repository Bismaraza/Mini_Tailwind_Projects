# Tailwind CSS Practice Projects

A collection of React + Tailwind CSS practice projects completed during Week 3.

## 🚀 Projects

### 1. Netflix-Inspired Navbar

A responsive streaming-platform style navbar built with React and Tailwind CSS.

**Concepts Practiced**
- Flexbox
- Spacing
- Alignment
- Responsive breakpoints
- Hover states
- Sticky navbar
- Typography
- Colors

---

**Concepts Practiced**
- Flexbox
- Sidebar layout
- `flex-1`
- Grid
- Responsive design
- Spacing
- Hover effects
- Shadows
- Rounded corners

💻 Run Locally

**Clone the repository:
**
git clone <your-repository-url>

**Move into the project:
**
cd <project-folder>

**Install dependencies:
**
npm install

**Start the development server:
**
npm run dev

**Build the project:
**
npm run build
